# When the revision is unknown

For per-revision lines from `board.py targets` that differ while the revision is unknown.

Run `board.py tell-apart "<user's words>"` and ask for the cheapest observation, then re-run `targets` with `--seen`. When only host or probe signals remain, follow the shared procedure SKILL.md names at this step. If the user can observe nothing, use the printed `safe default` and pass on what it gives up; on `no safe default`, identify the revision.
